How it works
This page is only a front end. Everything it does is sending the text frames listed below over the serial port and reading the replies, so the bench can also be driven from a serial terminal, MATLAB, Python or any other program that can open a serial port (see the README for examples).
Serial settings: 2,000,000 baud, 8 data bits, no parity, 1 stop bit (8N1). Everything is plain ASCII text. Each frame is one line ending in \n (a \r before it is ignored), at most 127 characters. The Arduino's replies end in \r\n.
There is no separate start command: each TYPE: frame starts one measurement as soon as it arrives. The Arduino runs NCYC cycles, sends all the samples in one DATA: line, and waits for the next frame. It does not read the port while measuring, so wait for END before sending anything else. Opening the port resets the Arduino, which answers OK:READY about 2 seconds later.
Frame format: KEY:value fields separated by commas, in any order. A field left out keeps its value from the previous frame. Decimal numbers use a point (0.50). Types below: float = 32-bit decimal number, integer = 32-bit signed whole number, text = letters or digits.

ReplyWhen
OK:READYAt power-up or reset (also when the port is opened).
WARN:NPTS_CLIPPED_TO_MAXNCYC × NPTS > 512: NPTS was reduced (in OLD, NCYC > 512 and NCYC was reduced).

DATA line
DATA:t,ch0,ch1;t,ch0,ch1;…;END
ValueTypeUnitMeaning
tunsigned 32-bit integerµsTime since the start of the signal, counted across all cycles.
ch0decimal, 4 decimalsVMCP3304 channel 0, node V01 of the TK042.
ch1decimal, 4 decimalsVMCP3304 channel 1, node V02 of the TK042.
ch0 and ch1 come from a 12-bit reading (0 … 4095 counts) converted as counts × 5 / 4095, so one count is about 1.22 mV and the range is −5 … +5 V. They are negative while the requested voltage is negative (reversed current). There are at most 512 samples per line; in OLD, one per pulse.
Console commands (this page only)
These are typed in the console below the log and are handled by the page; they are not sent to the Arduino. Any line starting with TYPE: is sent to the Arduino as it is (decimal commas such as 0,5 are changed to points).

THD (total harmonic distortion) versus frequency: sweeps the sine signal (with the current amplitude/offset from the Sine tab) from 5 Hz to 5000 Hz on a logarithmic scale. For each frequency it captures 10 real periods of CH0, computes the FFT, finds the first peak (fundamental, index p) and its harmonics (n·p), and obtains THD = √(V₂²+V₃²+...+Vₙ²)/V₁.
